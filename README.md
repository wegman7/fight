# Fight

A 2.5D platform fighter: 3D graphics in Godot 4, with gameplay in a pure-Rust deterministic simulation.

```
sim/      fight_sim — all gameplay rules: fixed-point physics, state machines,
          frame data, hitboxes, Smash knockback formula. No engine deps.
gdext/    fight_gd — Godot extension (godot-rust): menus, input → sim → 3D nodes
godot/    Godot project (main.tscn: lighting, camera, beach backdrop; shaders/; models/; music/)
art/      Blender sources for models (chef, pug, samurai, ninja, soldier, hobo, pie, grenade, stage, beach props), each generated by a Python script
```

The sim steps at a fixed 60 Hz from a list of per-player `Input`s. It uses only
integer (Q16.16) math, so the same inputs give bit-identical results on
Mac, Windows and Linux. That makes replays and rollback netcode possible later.
The Godot layer only reads the sim state and draws it.

More detail: [`sim/README.md`](sim/README.md), [`gdext/README.md`](gdext/README.md),
[`art/fighter/README.md`](art/fighter/README.md), [`art/pug/README.md`](art/pug/README.md),
[`art/samurai/README.md`](art/samurai/README.md), [`art/ninja/README.md`](art/ninja/README.md),
[`art/soldier/README.md`](art/soldier/README.md), [`art/hobo/README.md`](art/hobo/README.md),
[`art/stage/README.md`](art/stage/README.md).

## Setup (once)

```sh
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh   # Rust
brew install --cask godot                                          # Godot 4.7+
brew install --cask blender                                        # only to change the model
```

If a terminal says `cargo: command not found`, run `. "$HOME/.cargo/env"` or open a new terminal.

## Run

```sh
cargo build                       # builds target/debug/libfight_gd.dylib
godot --path godot                # play: menus, then the match
FIGHT_CPU=3 godot --path godot    # skip the menus: you (P1) vs a level-3 CPU (1-9)
FIGHT_DEMO=1 godot --path godot   # skip the menus: two level-3 CPUs fight, hitboxes shown
FIGHT_STAGE=sandbar FIGHT_CPU=9 godot --path godot   # FIGHT_STAGE picks the stage for either
FIGHT_CHARACTERS=samurai,pug FIGHT_CPU=3 godot --path godot   # and FIGHT_CHARACTERS P1's and P2's characters
FIGHT_MUSIC_VOLUME=50 godot --path godot   # music volume 0-100 (default 70)
godot -e --path godot             # open the editor (F5 runs the game)
```

Rebuild with `cargo build` after every Rust change. The editor hot-reloads the extension.

On a fresh clone, Godot needs to import the project once so it registers the
extension. Opening the editor does this, or run `godot --headless --path godot --import`.

## Test

```sh
cargo test                        # all sim tests and menu tests (milliseconds, no window)
cargo test jab                    # only tests whose name contains "jab"
cargo test -- --nocapture         # show println! output
cargo clippy --workspace --all-targets
```

Tests live in `sim/tests/gameplay.rs`, `sim/tests/pug.rs`, `sim/tests/samurai.rs`, `sim/tests/ninja.rs`, `sim/tests/soldier.rs`, `sim/tests/hobo.rs` and `sim/tests/cpu.rs` (plus unit tests in
`sim/src/fixed.rs`). The menus' logic is tested in `gdext/src/menu.rs`.
See [`sim/README.md`](sim/README.md#writing-tests) for how to write one.

For feel, playtest with the debug keys below: **H** to see hitboxes, then
**P** / **F** to step a move frame by frame.

## Menus

Like Melee, a match is set up in three screens:

1. **Stock match**: left / right picks the number of stocks (1-99, hold to scroll), then
   confirm or Start.
2. **Character select**: each port has a hand cursor in its color (P1 red, P2 blue, P3
   yellow, P4 green). A human's coin starts in their hand: move it onto a portrait and
   press A to drop it there. B takes your coin back. Each player panel has a
   **HMN / CPU / N/A** button that any hand can click (ports with no controller skip HMN),
   and CPU panels have a **level 1-9** slider: click a cell. CPU coins can be picked up
   and moved to another character by any hand. Once two or more players have picked,
   **READY TO FIGHT!** shows: press Start.
3. **Stage select**: any stick moves the cursor; pick **Boardwalk** (three rafts),
   **Sandbar** (flat, no platforms), **Driftwood** (one raft) or **Random**.

| | Move hand | A (confirm) | B (coin back) | Start | Back a screen |
|---|---|---|---|---|---|
| P1 keyboard | WASD | J | L | Enter | Esc (quits from the first screen) |
| P2 keyboard | Arrows | , | / | | |
| Gamepad in port n | Left stick / D-pad | A (right) | B (bottom) | Start | View / Back / − |

The nth connected gamepad is port n (pad 1 shares port 1 with the P1 keys). Ports 3 and
4 only have a hand when a third / fourth pad is connected; without one they can still be CPUs.

## Controls

| | Move | Attack | Jump | Special | Shield | Grab | Smash |
|---|---|---|---|---|---|---|---|
| P1 keyboard | WASD | J | K / Space | L | ; | U | I |
| P2 keyboard | Arrows | , | . | / | M | N | B |
| Gamepad in that player's port | Left stick / D-pad | A (right) | X / Y | B (bottom) | ZL / ZR | L / R | Right stick |

The controls follow Smash. "Forward" is the way you face. There are six characters
with their own movesets and tuning: the **chef** (an all-rounder in chef's whites, toque
and apron), the **pug** (small, light and quick, with two air jumps), the **samurai**
(a katana with the longest reach, a little heavier and slower to start), the **ninja**
(the lightest and fastest: low damage per hit, but quick combo-heavy knife-hands, in a
dark gi with a face wrap, headband and shuriken pouch), the **soldier** (the
heavyweight: slow and falls fast, but hits hard — a masked operator in a combat helmet,
goggles, ear-pro and a plate carrier hung with pouches, with a scoped carbine, grenades, a blast jump and a riot shield) and
the **hobo** (a drunken-fist brawler: floaty and wobbly,
attacking from odd angles).

How each input works, with the chef's moves:

| Where | Input | Move |
|---|---|---|
| Ground | Attack (neutral) | Jab. Press again for jab 2, then jab 3. |
| Ground | Direction + attack | Forward / up / down tilt. Down tilt also works from a crouch. |
| Ground | Attack while running | Dash attack |
| Ground | Flick the stick + attack together, or Smash (+ direction) | Forward / up / down smash. Hold attack (or Smash) to charge, for up to 1.4x damage. |
| Air | Attack (+ direction) | Neutral / forward / back / up / down air. Back air is the stick pointing away from where you face. Smash or the right stick also works. |
| Anywhere | Special (neutral) | Pie throw: lobs a cream pie that arcs about head height and splats on the floor about half a stage away |
| Anywhere | Special + sideways | Lunge forward. Once per trip through the air. |
| Anywhere | Special + up | Rising uppercut: the recovery move. You're helpless (special fall) until you land. |
| Anywhere | Special + down | Ground pound. It meteors (sends straight down) on the way down and makes a shockwave on landing. Off-stage, it falls all the way. |
| Ground | Grab (or attack while shielding) | Grab. Running makes it a dash grab. It catches shielding opponents. |
| Holding someone | Attack / direction | Pummel / forward, back, up, down throw |
| Being held | Mash any button or the stick | Break free sooner |
| Ground | Hold shield | Shield. It shrinks while held and when hit, and breaks (dizzy) at zero. |
| Shield | Jump / attack or grab / up + special / up smash | Jump, grab, up special or up smash straight out of shield |
| Shield | Stick sideways / down | Roll forward or back / spot dodge, both invincible partway through. Pressing shield with the stick already held does the same. |
| Air | Shield (+ direction) | Air dodge: in place, or a quick dash that way. Once per trip through the air. |

Falling past a solid platform's ledge grabs it (soft, pass-through platforms have no
grabbable edges): you hang there briefly invincible, and your double jump is restored.
From a hang, up or toward the stage climbs up, jump ledge-jumps, shield rolls up, attack
does a getup attack, and down or away drops off. Only one fighter can hold a ledge —
grabbing an occupied one knocks its holder off.

The pug's moves for the same inputs:

| Input | Pug move |
|---|---|
| Jab | Bite, bite, then keep pressing for a flurry of nibbles |
| Forward / up / down tilt | Low paw swipe / head toss (juggles) / butt scoot that slides forward and pops opponents up |
| Dash attack | Belly slide |
| Forward / up / down smash | Ram (lunges forward as it hits) / howl straight up / wet-dog shake that hits both sides |
| Neutral / forward / back / up / down air | Tail-chasing spin / headbutt / double back kick (buck) / snap upward / belly-flop pancake that meteors |
| Special (neutral) | Sneeze. Hold special to charge the "ah… ah…" (up to 1 s, then it fires by itself): a tap is a small, short puff; a full charge is a big, slow cloud that launches hard and knocks the pug back. |
| Special + sideways | Pounce tackle: a leap that latches onto whoever it catches and rides them for three bites, then kicks off. Whiffs on shields. Once per trip through the air. |
| Special + up | Ear copter: a slow, steerable climb, higher than the uppercut. Helpless after. |
| Special + down | Play dead: if hit while lying belly-up (frames 6-26), it takes no damage and pounces on the attacker |
| Grab, pummel, throws | Bite grab (shorter reach), nom, then toss forward / tug-of-war spin that flings them behind (the kill throw) / fling up / sit on them (pops them up for a combo) |

The samurai's moves. His blade hits hardest at the tip on the forward tilt, thrust and
forward smash:

| Input | Samurai move |
|---|---|
| Jab | Slash, backhand slash, then a long thrust |
| Forward / up / down tilt | Level cut at arm's length / rising arc over his head / kneeling sweep along the floor |
| Dash attack | Running cut |
| Forward / up / down smash | Two-handed overhead cleave / upward cut / spin sweep, in front then behind |
| Neutral / forward / back / up / down air | Full turn of the blade around him / downward arc / cut behind / arc overhead / downward stab that meteors |
| Special (neutral) | Focus cut: raises the blade and gathers himself, then a sweeping cut. Hold special to charge it (up to 1 s, then it swings by itself): a full charge does 24% and launches far harder than a smash attack. |
| Special + sideways | Vault: a crouch, then a hop up over whoever is in front, turning around at the top to land behind them. Press attack once airborne to strike straight down instead (a meteor). Once per trip through the air. |
| Special + up | Cyclone: spins with the blade held level as he climbs, cutting both sides, steerable. Helpless after. |
| Special + down | Parry: if hit in frames 5-24, he takes no damage and ripostes |
| Grab, pummel, throws | The chef's grab with his free hand, a hilt bash, then hip throw forward / shoulder throw behind (the kill throw) / toss up / knee pin (pops them up for a combo) |

The ninja's moves. Every move — including grab, dash grab and pummel — is his own, and
his hits are fast but light:

| Input | Ninja move |
|---|---|
| Jab | Kunai: three quick knife-hand slashes, chained by pressing attack again |
| Forward / up / down tilt | Palm thrust / rising chop (juggles) / low sweeping kick |
| Dash attack | Dash slice: a sliding slash out of a run |
| Forward / up / down smash | Two-hand overhead chop / rising flip kick / low spin kick that hits both sides |

| Special (neutral) | Shuriken: a fast, straight throw |
| Special + sideways | Shadow dash: a quick, intangible dash past the opponent, slashing as it goes. Once per trip through the air. |
| Special + up | Smoke bomb: vanishes (intangible) and reappears higher, then helpless |
| Special + down | Substitution: if hit in frames 5-24, a log appears and he strikes back |
| Grab, pummel, throws | His own grab and a kunai-hilt pommel, then a forward throw / a flip throw behind (the kill throw) / an upward toss / a floor slam that pops them up for a combo |

The soldier's moves. The heavyweight: his hits land hard and the rifle reaches out
past the chef's fists, in exchange for slower startups:

| Input | Soldier move |
|---|---|
| Jab | Rifle-butt strike, then a second, harder butt strike |
| Forward / up / down tilt | Bayonet thrust (hardest at the tip) / rifle swung up over his head / low leg sweep that trips and pops opponents up |
| Dash attack | Shoulder charge, carried forward on his run |
| Forward / up / down smash | Heavy rifle-stock smash / upward bayonet / spinning stock sweep, in front then behind |
| Neutral / forward / back / up / down air | Spin with the rifle / airborne bayonet thrust / back elbow / upward rifle jab / downward stomp that meteors |
| Special (neutral) | Rifle shot: a fast, straight bullet |

| Special + down | Riot shield: if hit in frames 6-26, he takes no damage and bashes the attacker back |

The hobo's moves. He's floaty and loose, and his swings come out late and lurch through
odd arcs — none of them are the chef's (even his grab is his own):

| Input | Hobo move |
|---|---|
| Jab | Swaying slap, backhand slap, then a lurching two-handed shove |
| Forward / up / down tilt | Lurching punch / upward flail / low trip that sweeps the floor |
| Dash attack | A stumbling dash that flails into them |
| Forward / up / down smash | Big bottle swing / heaves the bottle up / drunken spin that flails both sides |
| Neutral / forward / back / up / down air | Flailing spin / wild haymaker / backhand swing / upward flail / downward stomp (a meteor) |
| Special (neutral) | Bottle throw: lobs a bottle that arcs and shatters where it lands, catching anyone close by |
| Special + sideways | Shopping-cart charge: crouches, then bursts forward fast behind a cart, plowing through whoever's in the way; leaves him wobbling (and helpless off a ledge) |
| Special + up | Fizz rocket: shakes a soda bottle and rides the fizz upward, a steerable recovery. Helpless after. |
| Special + down | Passed out: flops over; if hit (frames 8-28), he takes no damage and jolts awake swinging |
| Grab, pummel, throws | His own headlock grab and a collar-shake pummel, then throw forward / sling them behind (the kill throw) / toss up / stumble them to the floor (pops them up for a combo) |

Tap down on a platform to drop through, or in the air to fast-fall. Hold down to
crouch. Release jump before liftoff for a short hop. Up alone does nothing: jump is
its own button (no tap jump yet).

On a keyboard every press is a full flick. So pressing a direction and J together
is a smash attack. Hold the direction a moment first to get a tilt, or use the
Smash key for smash attacks on purpose.

In a match: pad **Start** pauses (then **View/Back** quits to character select). **Esc**
goes back to character select. **R** restarts the match. Once someone wins, **Start** /
**Enter** goes back to character select, keeping everyone's picks.

Debug: **H** hitboxes · **P** pause · **F** frame-advance · **-** / **=** music volume

Music: `untitled` plays in the menus and `rising_motif` during every match, both looping.
Set the volume with `FIGHT_MUSIC_VOLUME` (0-100) or the `-` / `=` keys (works in menus and matches).

Pad buttons use the Switch layout, as in Smash Ultimate: A is the right face button and
B the bottom one, by position. So on an Xbox pad attack is B and special is A; on a
PlayStation pad they are ○ and ✕. In the tables, ZL / ZR are the triggers (LT / RT,
L2 / R2) and L / R the bumpers (LB / RB, L1 / R1).

Xbox, PlayStation and Switch Pro pads all work (Godot uses SDL's mappings). On
macOS, pair Xbox One/Series pads over Bluetooth. The game prints each detected
joypad's name to the console at startup and whenever one connects.

## Where things live

- Characters and which move each input starts: `sim/src/character.rs` (`Character`, `Moveset`)
- Character tuning: `FighterParams::CHEF` / `PUG` / `SAMURAI` / `NINJA` / `SOLDIER` / `HOBO` in `sim/src/fighter.rs`
- Moves, dodges and frame data: `sim/src/moves.rs`, the chef's first, then the pug's, then the samurai's, then the ninja's, then the soldier's, then the hobo's (reading inputs into a move slot is in `Fighter::step`)
- Stage layouts and blast zones: `StageId` (the selectable list) and `Stage::battlefield()` / `flat()` / `single_platform()` in `sim/src/stage.rs`
- Stage look (boardwalk on a floating rock, driftwood rafts): `art/stage/build_stage.py` → `godot/models/stage.glb` and `raft.glb`, textured by `godot/shaders/wood.gdshader` and `stone.gdshader`
- Knockback / hitstun / hitlag formulas: bottom of `sim/src/fighter.rs`. Shield, grab and smash-charge numbers: constants near the top.
- Hits, grabs, throws and projectiles between fighters: `World` in `sim/src/world.rs`
- CPU opponent: `sim/src/cpu.rs` (`LEVELS` holds the difficulty knobs for levels 1-9; `CpuLevel::EASY` is level 3)
- Menus: `gdext/src/menu.rs` (state, layout, what each press does) and `gdext/src/menu_view.rs` (drawing)
- Background music: `gdext/src/music.rs` loads and loops `godot/music/untitled.mp3` (menus) and `godot/music/rising_motif.mp3` (matches)
- Controls, camera, visuals: `gdext/src/lib.rs`
- Chef model, animations and the pie: `art/fighter/build_fighter.py` → `godot/models/fighter.glb` and `pie.glb`, shaded by `godot/shaders/chef_*.gdshader` (skin, cloth, hair and everything else) via `fighter_*.tres` / `pie_*.tres`
- Pug model and animations: `art/pug/build_pug.py` → `godot/models/pug.glb`
- Samurai model and animations: `art/samurai/build_samurai.py` → `godot/models/samurai.glb`
- Ninja model and animations: `art/ninja/build_ninja.py` → `godot/models/ninja.glb`
- Soldier model, animations and the grenade: `art/soldier/build_soldier.py` → `godot/models/soldier.glb` and `grenade.glb`, its fatigues textured by `godot/shaders/camo.gdshader`, its gear by `godot/shaders/gear.gdshader` and its rifle metal by `godot/shaders/weapon.gdshader` (shared helpers in `godot/shaders/soldier.gdshaderinc`)
- Hobo model and animations: `art/hobo/build_hobo.py` → `godot/models/hobo.glb`
- Which model draws each character: `look()` in `gdext/src/lib.rs`
